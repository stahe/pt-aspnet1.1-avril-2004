## Introdução

Este documento é um **recurso educativo** destinado a estudantes e não pretende ser um curso exaustivo. Alguns tópicos requerem a orientação de um professor, e vários aspetos do desenvolvimento web foram deliberadamente omitidos. 

Este recurso faz parte de uma série de documentos dedicados ao **desenvolvimento web**, um tema que o autor já explorou anteriormente através de duas tecnologias:

* **Java**
* **PHP**

Estes documentos partilham uma **estrutura educativa semelhante**, o que permite comparar as diferentes tecnologias através de exemplos análogos.

## Abordagem educativa

Ao contrário de muitos livros sobre ASP.NET, este recurso não se centra imediatamente na ideia de que uma aplicação web ASP.NET pode ser desenvolvida como uma **aplicação Windows**.

Na literatura tradicional sobre ASP.NET:
* a interface do utilizador é normalmente criada em ambientes de desenvolvimento integrado (IDE) como o **Visual Studio .NET** ou o **WebMatrix**;
* os **controlos gráficos** são colocados dentro de uma interface visual;
* estes controlos têm **propriedades, métodos e eventos**;

Neste documento, estes conceitos são apresentados deliberadamente **mais adiante no curso**, uma vez que são considerados importantes, mas **não fundamentais** para compreender o desenvolvimento web.

## Objetivo principal

A primeira parte do documento centra-se nos **fundamentos do desenvolvimento web**, independentemente da tecnologia utilizada (Java, PHP ou ASP.NET).

É dada especial atenção à arquitetura:

**MVC — Modelo / Vista / Controlador**

Esta arquitetura é frequentemente recomendada para projetar aplicações web estruturadas e fáceis de manter.

No entanto, a abordagem MVC é relativamente incompatível com a filosofia do ASP.NET de projetar uma aplicação web como uma aplicação Windows. Por este motivo, os mecanismos específicos do ASP.NET destinados a aumentar a produtividade são abordados **na segunda parte do curso**.

## Ferramentas utilizadas

Este documento centra-se exclusivamente em **ferramentas disponíveis gratuitamente na Internet**, para que os alunos possam:

* descarregá-las facilmente;
* instalar o ambiente nos seus computadores pessoais;
* reproduzir e experimentar os exemplos apresentados;

Um apêndice intitulado **«Ferramentas web»** explica como obter e instalar estas ferramentas.
